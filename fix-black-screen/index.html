Smoothie goes black on Netflix — the 2-minute fix

One line, pasted into your browser shortcut. Video quality stays the same. Nothing to install. Reversible anytime.

1

Copy this line

--disable-direct-composition

The button flips to Copied ✓. Don't paste it anywhere yet.

2

Right-click the icon → Properties

On the desktop, right-click the Google ChromeMicrosoft Edge icon you open the browser with. Properties is near the bottom of the menu.

Icon not on the desktop? Right-click it in the taskbar, then right-click the browser name in the small menu, then Properties.

3

Paste into Target, click OK

Click at the very end of the Target field — the one with the long path. Type one space, press Ctrl+V, click OK. Your field must look exactly like this:

Don't delete anything already in the field. If Windows says the name is invalid — check there's exactly one space between the path and the line.

4

Restart the browser completely

Close every ChromeEdge window. Check the corner next to the clock — if the browser's small icon is still there, right-click it → Exit. Then open the browser again from the same desktop icon.

Back on Netflix: fullscreen → Smoothie. The picture fills the screen.

✓ Done — sorry for the inconvenience

This is a Chrome/Edge limitation, not a bug in Ultrawider — but we know it's frustrating. To undo: repeat steps 2–3 and delete the pasted line.

Still black?

Go back to your video tab and try Smoothie again. If the problem persists, Ultrawider itself will offer you to send a report — right from the player, with all the technical details attached automatically. No forms to fill in.

What does this line actually do?

Protected (DRM) video is drawn on a special fast layer beside the page; our non-linear warp can't process it, and on some PCs that layer shows black instead. The line switches your browser to its standard drawing path. The video keeps all of its protection and quality; the trade-off is a slightly older rendering route, which can rarely cause minor visual quirks on other sites.

The fix works only when the browser starts from that shortcut

Windows stores the line in the shortcut itself. If you open the browser from somewhere else, repeat steps 2–3 on that shortcut — or pin the fixed desktop shortcut to the taskbar and use it.
