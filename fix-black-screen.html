Smoothie shows a black screen on Netflix — the 2-minute fix

This is a quirk of Chrome on Windows with protected video. One paste in your Chrome shortcut fixes it. Nothing to install, and you can undo it anytime.

What's happening: sites like Netflix, Max and Disney+ play their video through extra protection (DRM). On Windows, Chrome draws that protected video on a special fast layer that Smoothie's warp cannot reach — so the picture turns black. One line, pasted into your Chrome shortcut, switches Chrome to the normal drawing path. Your video quality stays the same.

TimeAbout 2 minutes
Skills neededCopy, paste, click — that's all
ToolsChrome on Windows, nothing else
Reversible?Yes — remove the line anytime
1

Copy the fix line

Click the button below. The line is now on your clipboard, ready for step 3.

--disable-direct-composition
You'll see: the button says Copied ✓. Don't paste it anywhere yet.
2

Right-click your Chrome icon → Properties

Find the icon you normally use to open Chrome — on the desktop or in the taskbar. Right-click it and choose Properties at the very bottom of the menu.

The menu opens on right-click. Properties is always the last item.
Chrome pinned to the taskbar? Right-click the icon, then in the small menu right-click Google Chrome again, then click Properties.
You'll see: a window titled “Google Chrome Properties”.
3

Paste the line at the very end of “Target”

In the Properties window find the field named Target. Click inside it, press End (or Ctrl+→) to jump to the very end of the text, type one space, then press Ctrl + V.

The Target field after pasting. The path stays untouched; space + line sits after it.
Don't delete anything that's already in the field — only add a space and the paste. If Windows says the name is invalid, check that there's exactly one space between chrome.exe" and the pasted line. Click OK.
You'll see: the window closes with no error.
4

Quit Chrome completely

Close all Chrome windows. Then — important — Chrome often keeps running near the clock in the bottom-right corner. Right-click that small Chrome icon → Exit. The fix only applies on a fresh start.

Right-click the small icon by the clock → Exit. No icon left there = Chrome is fully closed.
You'll see: the small Chrome icon disappears from the corner.
5

Open Chrome the same way as always

Double-click the same icon you edited (the fix lives in that shortcut). Go back to Netflix, go fullscreen and switch on Smoothie.

You'll see: the picture — warped to fill your screen, no black.

How do I know it worked?

The honest check is the picture itself. If you like checking under the hood: type chrome://version in the address bar and look at the Command Line field — it must contain --disable-direct-composition.

Done — Smoothie fills the screen

Enjoy. If you ever want to undo this, open Properties again and delete the pasted line. That's it.

What does this line actually do?

Chrome on Windows draws protected (DRM) video on a special hardware layer that runs beside the page. Smoothie's non-linear warp has to process the picture itself, and that layer doesn't allow it — some PC configurations show black instead. The line tells Chrome to use its standard drawing path for everything; protected video keeps all of its protection and your streaming quality stays the same. The trade-off: Chrome renders through a slightly older route, which in rare cases causes minor visual quirks on other sites. Removing the line restores everything exactly as it was.

Using Edge instead of Chrome?

Exactly the same steps — right-click your Edge shortcut, Properties, paste the same line after the path, fully quit Edge, open it again.

The fix works only when Chrome starts from that shortcut

Windows stores the line in the shortcut itself — links from other places (Start menu search, another app) won't have it. If you usually open Chrome differently, do the same two edits (Target field) on that shortcut too, or drag your fixed shortcut to the taskbar and use it from now on.
