Smoothie goes black on Netflix
— the 2-minute fix

One line, pasted into your browser shortcut. Video quality stays the same, nothing is installed, and you can undo it anytime.

STEP 1

Copy this line

--disable-direct-composition

The button flips to Copied ✓. Don't paste it anywhere yet.

STEP 2

Open your ChromeEdge shortcut's Properties

On the desktop, right-click the Google ChromeMicrosoft Edge icon — the one you open the browser with. Then click Properties, the highlighted row below.

Icon not on the desktop? Right-click it in the taskbar, right-click the browser name in the small menu, then Properties.

STEP 3

Paste the line into Target

Click at the very end of the Target field (the one with the long path), type one space, press Ctrl+V — then click OK. This is how the field must look:

2click OK
1your pasted line

Don't delete anything already in the field. If Windows says the name is invalid — check there's exactly one space between the path and the line.

STEP 4

Restart the browser completely

Close every ChromeEdge window. Then check the corner next to the clock — if the browser's small icon is still there, right-click it → Exit. Open the browser again from the same desktop icon.

Back on Netflix: fullscreen → Smoothie. The picture now fills the screen.

Done

To undo: repeat steps 2–3 and delete the pasted line.

What does this line actually do?

Protected (DRM) video is drawn on a special fast layer beside the page; our non-linear warp can't process it, and on some PCs that layer shows black instead. The line switches your browser to its standard drawing path. The video keeps all of its protection and quality; the trade-off is a slightly older rendering route, which can rarely cause minor visual quirks on other sites.

The fix only works when the browser starts from that shortcut

Windows stores the line in the shortcut itself. If you open the browser from somewhere else, repeat steps 2–3 on that shortcut — or pin the fixed desktop shortcut to the taskbar and use it.
